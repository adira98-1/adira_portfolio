# Project Summary

## Objective

Build an end-to-end retail analytics platform using Snowflake, DBT, Snowpark, Python, and AI.

## Key Deliverables

* Snowflake data warehouse
* DBT transformations
* Star schema design
* Data quality tests
* Snowpark integration
* Sentiment analysis using TextBlob
* AI results stored back in Snowflake

## Technologies

* Snowflake
* SQL
* DBT
* Snowpark
* Python
* Git
* TextBlob

## Outcome

Created a complete analytics pipeline capable of transforming retail data and generating AI-powered sentiment insights.
